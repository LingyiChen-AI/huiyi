# 界面语言即时切换

用户已选择立即生效。采用现有 WPF 和 .NET 资源系统，支持简体中文、繁体中文、英文、日文和韩文，默认跟随系统。界面语言与字幕目标、纪要输出语言分别保存。

- [x] 核心资源服务负责系统语言匹配、格式参数和缺失文案回退，保持模型提示、会议内容及用户输入原样。
- [x] XAML 使用绑定标记扩展，代码创建的控件使用可刷新的文案绑定。切换语言时保留窗口、当前页、编辑内容和录制状态。
- [x] 设置通用页加入语言选择，托盘菜单与窗口同步刷新。安装向导按系统语言显示。
- [x] 为本地化解析、占位符和资源完整性增加回归测试，运行现有测试和五种语言截图检查。

实现取舍由本次开发确定。共享资源放在核心项目，以便安装向导复用。使用中文源文案作资源键，便于排查未翻译项。默认回退英文，中文资源作为最终回退。
